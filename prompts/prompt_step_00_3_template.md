## ИНСТРУКЦИИ ПО ПРОФИЛЯМ

### ПРОФИЛЬ: Папки

**Описание:** Обработка файловой структуры и организация директорий.

**Инструкции:**
1. **Анализ структуры:**
   - Определи иерархию директорий
   - Выдели корневые и вложенные папки
   - Зафиксируй глубину вложенности

2. **Правила именования:**
   - Примени паттерны именования из Секции H
   - Проверь соответствие стандартным шаблонам
   - Выяви отклонения от стандартов

3. **Организация файлов:**
   - Определи типы файлов в каждой директории
   - Зафиксируй правила распределения файлов
   - Выдели специальные директории (архивы, временные, системные)

4. **Оптимизация структуры:**
   - Предложи улучшения организации
   - Выяви дублирующиеся директории
   - Зафиксируй рекомендации по реструктуризации

**Результат:**
```
СТРУКТУРА ПАПОК:
- [Путь]: [описание назначения]
  * Типы файлов: [список]
  * Правила именования: [применяемые паттерны]
  * Рекомендации: [если есть]
```

### ПРОФИЛЬ: Паттерны

**Описание:** Извлечение и анализ паттернов из данных.

**Инструкции:**
1. **Идентификация паттернов:**
   - Примени инструкции из Промта №0.2
   - Извлеки паттерны по всем секциям (A-D, H-O)
   - Проверь на соответствие исключениям

2. **Систематизация:**
   - Сгруппируй паттерны по категориям
   - Определи приоритеты применения
   - Зафиксируй зависимости между паттернами

3. **Валидация:**
   - Проверь каждый паттерн на корректность
   - Выяви противоречия между паттернами
   - Зафиксируй случаи неопределённости

4. **Документирование:**
   - Создай каталог паттернов
   - Добавь примеры применения
   - Зафиксируй ограничения и исключения

**Результат:**
```
КАТАЛОГ ПАТТЕРНОВ:
Секция [Буква]: [Название]
- Паттерн: [описание]
  * Формат: [формат]
  * Применение: [когда использовать]
  * Исключения: [когда не использовать]
```

### ПРОФИЛЬ: Документы

**Описание:** Обработка содержимого файлов и документов.

**Инструкции:**
1. **Анализ содержимого:**
   - Определи тип документа (текст, код, данные, конфигурация)
   - Извлеки структуру документа
   - Выдели ключевые элементы

2. **Применение паттернов:**
   - Примени паттерны из Секции K (контент)
   - Проверь соответствие форматам
   - Выяви отклонения от стандартов

3. **Извлечение метаданных:**
   - Примени паттерны из Секции J (метаданные)
   - Извлеки встроенные метаданные
   - Зафиксируй атрибуты документа

4. **Валидация контента:**
   - Проверь синтаксическую корректность
   - Выяви логические противоречия
   - Зафиксируй рекомендации по улучшению

**Результат:**
```
АНАЛИЗ ДОКУМЕНТА:
- Файл: [путь]
  * Тип: [тип документа]
  * Структура: [описание структуры]
  * Метаданные: [извлечённые метаданные]
  * Соответствие паттернам: [статус]
  * Рекомендации: [если есть]
```

## Общие правила для всех профилей

1. **Приоритет исключений:** Исключения всегда имеют приоритет над стандартными правилами
2. **Принцип минимального вмешательства:** Не изменяй данные без явной необходимости
3. **Принцип документирования:** Фиксируй все принятые решения и их обоснование
4. **Принцип проверяемости:** Результат должен быть воспроизводим и проверяем
