# Журнал изменений промтов

Формат записи: `ГГГГ-ММ-ДД — <промт> — <краткое описание>`. Записи не редактируются (append-only). Старые промты не удаляются — новые версии добавляются отдельными файлами.

## 2026-10-30 — Промты №0.1, №0.2, №0.3 — стабилизированы после отладки

- **Что сделано:** Промт №0 разделён на три независимых промта:
  - **№0.1** (`prompt_step_00_1_template.md`) — базовые типы из Конфигурации (XML). Выход: `{{СПИСОК_БАЗОВЫХ_ТИПОВ}} = <имя>` (18 типов, эталон подтверждён).
  - **№0.2** (`prompt_step_00_2_template.md`) — паттерны и типы-справочники из Схемы. Выход: `Паттерн|Типы|Количество` + `ТИПЫ-СПРАВОЧНИКИ` + статистика.
  - **№0.3** (`prompt_step_00_3_template.md`) — список шагов, один шаг за вызов. Вход: `{LAST_STEP_NUMBER}` (нет / 0 / 00[.i] / 01 / 01.i / 01.i.k / NN), `{INPUT_FILENAME}`, `{DESCRIPTION_FILENAME}`, `{EXTRA_DATA_LIST}`. Выход: 5-колоночный формат `NN|<типы>|<K>|<Паттерн>|<предупреждение>` + блок «ТРЕБУЮТ РЕШЕНИЯ ПОЛЬЗОВАТЕЛЯ» + статистика.
- **Кто:** ИИ-оркестратор (тексты шаблонов) + отладочный чат (прогоны, итерации).
- **Как проверялось:** прогоны в ИИ-Генераторе на эталонных файлах: Промт №0.1 — 18 типов (эталон совпал); Промт №0.2 — CSV `Паттерн|Типы|Количество`; Промт №0.3 — 5-колоночный формат, баланс строк, СТОП-правила.
- **Принятые решения:**
  - `{LAST_STEP_NUMBER}` — расширенный формат (финальный).
  - Документы в Шаге 0 — отфильтровываются, в блок «ТРЕБУЮТ РЕШЕНИЯ» не идут.
  - Пороги `P > 50` / `ΣK > 500` — настраиваемые (лист «Настройки» Препроцессора).
  - Склейка `Шаги.txt` — вручную пользователем (через буфер обмена); Генератор файлы не сохраняет.
- **Открытые вопросы:**
  - Промт №0.2: паттерны — не догма (пользователь может пропустить); на листе «Настройки» — «Список приоритетных типов»; ИИ должен предлагать свои паттерны и уметь возвращать список в таблицу для повторных прогонов. Требует доработки шаблона №0.2.
  - Промт №0.4 (выжимка ГОСТа и Описания) — в разработке.
  - Перенос №0.1 на Python — в backlog (`W-MIGRATE-STEP01-TO-PYTHON`).
- **Следующий шаг:** доработка №0.2 (приоритетные типы, итерации), разработка №0.4 (выжимка), затем — правки кода `Mod_Prompt.bas` / `Mod_Folders.bas` под три промта.
