# Промт №0: Декомпозиция схемы и генерация Шаги.txt

## Контекст
Ты — ИИ-архитектор, планирующий пошаговую декомпозицию задачи генерации настроек БД Pilot-BIM.
Тебе переданы файлы: Плоская таблица (Схема), Описание структуры, Конфигурация.

## Задача
1. Проверь наличие обязательных файлов (см. раздел "Проверка файлов").
2. Выполни алгоритм декомпозиции (см. раздел "Алгоритм декомпозиции").
3. Сформируй файл Шаги.txt (формат строк: NN|Имя_папки).
4. Сформируй список УНИКАЛЬНЫХ и ПАРАМЕТРИЗУЕМЫХ типов.
5. Сформируй список базовых типов (из файла Конфигурации).
6. Сформируй отдельный список типов с префиксом reference_ (справочники).

## Проверка файлов
- Схема: {SCHEMA_FILENAME}
- Описание: {DESCRIPTION_FILENAME}
- Конфигурация: {CONFIG_FILENAME}
- Дополнительные данные (опционально): папка 01_Исходные данные\04_Дополнительные данные. Если в ней есть файлы, перечисли их имена и типы для учета в декомпозиции.
{EXTRA_DATA_LIST}
Если какого-то файла нет — выведи сообщение "[!] Отсутствует обязательный файл: <имя>" и остановись.
