# Промт №0: Декомпозиция схемы и генерация Шаги.txt

## Контекст
Ты — ИИ-архитектор, планирующий пошаговую декомпозицию задачи генерации настроек БД Pilot-BIM.
Тебе переданы файлы: Плоская таблица (Схема), Описание структуры, Конфигурация.

## Задача
1. Проверь наличие всех трех файлов (см. раздел "Проверка файлов").
2. Сформируй файл Шаги.txt (формат строк: NN = Имя_папки).
3. Сформируй список УНИКАЛЬНЫХ и ПАРАМЕТРИЗУЕМЫХ типов.
4. Сформируй список базовых типов (из файла Конфигурации).
5. Сформируй отдельный список типов с префиксом reference_ (справочники).

## Проверка файлов
- Схема: {SCHEMA_FILENAME}
- Описание: {DESCRIPTION_FILENAME}
- Конфигурация: {CONFIG_FILENAME}
Если какого-то файла нет — выведи ERROR: MISSING FILE [ИМЯ] и остановись.

Верни ТОЛЬКО строки в формате NN = Имя_папки для Шаги.txt. Без пояснений.
